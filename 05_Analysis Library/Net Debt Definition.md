# Net Debt Definition

Every filled-in number must carry a shown derivation or a citation — never bare.

**Indebtedness** (everything that reduces purchase price):

| Category | Standard Treatment | Notes |
|---|---|---|
| Term loans | Debt | All |
| Revolver (drawn) | Debt | Outstanding balance only |
| Capital / finance leases (ASC 842) | Debt | All operating leases post-2019 |
| Pension underfunding (PBO/ABO gap) | Debt-like | Actuarial-grade |
| Multi-employer pension withdrawal liability | Debt-like | Often 5-10× annual contribution |
| OPEB obligations | Debt-like | Re-measured at low discount rates |
| Deferred compensation | Debt-like | Including NQDC, SERPs |
| Accrued bonuses outside ordinary course | Debt-like | Above 12-month average |
| Earn-outs from prior deals | Debt-like | NPV of expected payments |
| Customer deposits (cash already collected against work) | Debt-like | Buyer's win |
| Deferred revenue (cash collected) | Debt-like (negotiated) | Seller's fight |
| Tax liabilities outside ordinary course | Debt-like | Uncertain tax positions |
| Litigation accruals | Debt-like | If probable + estimable |
| Environmental reserves | Debt-like | Phase II contamination |
| Restructuring accruals | Debt-like | If post-close cash outflow |
| Transaction expenses unpaid at close | Debt-like | Including bonuses to mgmt |
| Change-in-control payments | Debt-like | If triggered by transaction |
| Swap MTM (negative) | Debt-like | NPV |
| Factoring / securitization | Debt-like | Off-balance-sheet financing |
| 401(k) match owed | Debt-like | Year-end accrual |
| Asbestos / mass-tort reserves | Debt-like | Outside R&W coverage typically |

**Cash** (everything that increases purchase price):

| Category | Standard Treatment |
|---|---|
| Unrestricted cash | Cash |
| Marketable securities | Cash |
| Tax overpayments expected as refunds | Cash (negotiated) |
| Restricted cash (legitimately segregated) | Excluded |
| Escrow | Excluded |
| Minimum operating cash | Excluded (negotiated as % of revenue) |

**Net Debt = Indebtedness − Cash**

The seller's fight is to keep items "operating" or in NWC; the buyer's QofE evidence package is what enables the negotiation.
