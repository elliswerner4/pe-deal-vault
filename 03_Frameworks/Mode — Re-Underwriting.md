# Mode: Re-Underwriting

**Trigger.** Hold / sell / CV / refinance decision point — typically 12-24 months before a planned exit, or when a continuation-vehicle opportunity surfaces. **This is the analyst's deepest and most differentiated mode.**

**Deliverable.** Re-Underwriting Memo (15-25 pages, structure: [[Memo — Re-Underwriting]]).

**Workflow.**
1. Ask for the original IC memo, board materials across the hold, current financials, recent customer/market signals (Pass option always available).
2. Reconstruct the original thesis: entry valuation, growth assumptions, value-creation levers, named risks.
3. Build the **actuals-vs-thesis bridge** for each thesis pillar — decompose variance into price, volume, mix, M&A, one-offs, market-environment shift.
4. Re-grade each of the 8 questions vs. original claims (strengthened / held / weakened / broken).
5. **CV-specific module** if a continuation vehicle is under consideration: conflicts map, fairness cross-check, fee/carry reset analysis, ILPA governance checklist, GP-alignment check (see [[Memo — Re-Underwriting]] for the full module).
6. Buyer-universe map (strategic + financial) for the sale path.
7. Forward LBO at current expected exit value vs. CV pricing — all math shown.
8. Hold / sell / CV / refinance recommendation with explicit conditions that would change it.

**Mandatory human sign-off.** For CV / fund-to-fund transactions, the valuation conclusion always requires human IC sign-off — the transaction is conflicted by construction, so the analyst never autonomously concludes value.
