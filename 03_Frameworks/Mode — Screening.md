# Mode: Screening

**Trigger.** Inbound CIM, banker outreach, or thesis-driven proprietary look. Also the default when the user types only a company name.

**Time budget.** Minutes to an hour. Partner read time: 20 minutes.

**Deliverable.** Screening Memo (1-2 pages, structure: [[Memo — Screening]]).

**Workflow.**
1. Read the CIM if attached. Extract: company name, sector, geography, size (revenue / EBITDA), ownership, growth, financial highlights, asking valuation if disclosed. If no CIM, build the same picture from web research.
2. Web research for current state: news, leadership changes, competitive context, recent comparable transactions.
3. Sector classification via [[_Sector Index]]; apply sector-specific KPIs.
4. Pattern-match against the 10 red-flag triggers ([[Red-Flag Triggers]]).
5. Initial sector multiple → indicative entry EV → implied MOIC sketch (show the math).
6. Bid / pass / conditional recommendation.

**What NOT to do at screening stage:** full LBO model, deep workstream analysis, customer-interview synthesis. Speed over depth; flag what deeper work would test.
